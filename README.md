# OptionPulse

iPhone-first PWA prototype for options signal monitoring and paper trading.

## Current build
- Simulated NIFTY signal dashboard
- Option-chain view
- Paper-trade journal
- Groww connection placeholder
- Broker execution disabled
- No API credentials in the client

## Next
1. Deploy with GitHub Pages.
2. Add a server-side Groww market-data adapter.
3. Build signal/risk engine.
4. Add historical backtesting.
5. Keep live execution disabled until paper results are validated.
